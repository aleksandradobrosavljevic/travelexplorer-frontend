# TravelExplorer — Frontend

TravelExplorer is a web application that helps tourists plan and organize their trips more easily. It was built as part of a 5-person team project and consists of four main modules, each tailored to a different type of user:

- **Tourist app** — users can browse an interactive map, explore destinations, choose routes, and discover sights such as restaurants, hotels, museums, and events (concerts, museum exhibitions, etc.). The tourist-facing interface is fully responsive and optimized for both desktop and mobile use.
- **Admin panel** — the main administrator manages the entire system: blocking/unblocking users, assigning destination admins, and reviewing analytics such as most visited hotels and most popular destinations.
- **Publisher panel** — publishers add and manage hotels, events, and activities, and can view reviews left for their listings.
- **Destination admin panel** — manages a specific assigned region, approving or rejecting activities, events, and hotels submitted by publishers for that destination, reviewing feedback, and tracking region-specific analytics.

**Note:** This repository contains the frontend portion of the project (Angular / TypeScript), developed together with one of the teammates. The backend and other parts of the application were developed by the rest of the team.

## Tech Stack
- Angular
- TypeScript
- HTML / CSS

## Getting Started

```bash
npm install
ng serve
```

Then open `http://localhost:4200` in browser.
